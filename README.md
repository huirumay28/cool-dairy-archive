# Cool Dairy Archive

Live site: https://huirumay28.github.io/cool-dairy-archive/

A static shop archive for cool dairy — icons and brands. No pulse, no shop.

## Add an icon or brand

1. Drop a JSON file in `content/icons/` or `content/brands/`.
2. Run `python3 generate.py`.
3. Commit and push. GitHub Pages updates from `main`.

Sources on every page. We do not invent designers or quotes.
