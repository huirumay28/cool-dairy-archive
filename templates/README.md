# Templates

Page chrome (header, footer, card, media) is rendered by `../generate.py`.

This folder is the place to keep chrome notes and any future HTML partials. Do not hardcode a list of icons or brands here. Grids come from `content/icons/*.json` and `content/brands/*.json`.

Icon page order, enforced by the generator:

1. Name + who-line
2. The person
3. The clothes
4. Sources
